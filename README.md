# WWCD_project

A finance tracker website for micro-SMEs, built with Next.js, Prisma and Supabase.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

Copy your own `.env` file with `DATABASE_URL`, `DIRECT_URL` and `GEMINI_API_KEY` (never commit it).
